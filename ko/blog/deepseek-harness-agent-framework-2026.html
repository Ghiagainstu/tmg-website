1. 발표: Harness 공개 및 오픈소스화

2026년 8월 13일 밤 — DeepSeek가 V4 Pro를 정식 버전으로 승격시킨 바로 그 날 — DeepSeek는 첫 에이전트 제품 DeepSeek Harness(v0.1 개발자 프리뷰)를 출시하고, GitHub에 오픈소스로 공개함과 동시에 NPM 레지스트리에 게시했다.

이 발표는 전격적인 더블 스트라이크였다: 2시간 안에 DeepSeek는 V4-Pro-0813 정식 출시와 Harness 공개 베타를 모두 발표했다. GitHub 저장소는 30분 만에 1만 스타를 넘었고 이후 3만을 초과했다.

DeepSeek Harness는 서양 시장의 주요 코딩·오피스 에이전트 제품인 OpenAI Codex와 Anthropic Claude Code에 대항하는 포지셔닝이다. DeepSeek의 내부 공식은 정확하다: "Model + Harness = Agent." 하네스는 모델을 에이전트로 변환하는 도구다: 컨텍스트, 도구, 태스크 상태, 피드백, 경계를 오케스트레이션하여 모델을 요구사항 이해에서 실제 환경에서의 코드 전달로 이끈다.

팀은 최천이(Cui Tianyi)가 이끌며, 8월 2일 전 세계 베타 테스터를 공개 모집했다. 프로젝트는 DeepSeek 브랜드의 고래 로고에 대한 의도적 오마주인 '검은 고래' 태그라인을 사용한다.

2. '모든 것이 플러그인': Cordis 아키텍처와 네 가지 모드

DeepSeek Harness의 결정적 아키텍처 선택은 '모든 것이 플러그인'(一切皆插件)이다. 고정된 도구 체인을 갖춘 전형적인 코딩 에이전트와 달리, DSH의 모든 역량 — 모델, 도구, 스킬, 세션, 샌드박스, 스토리지, 루프, 스케줄링, UI — 은 자유롭게 교체·재조합할 수 있는 플러그인으로 구성된다.

기반은 Cordis 플러그인 시스템으로, 플러그인 로딩, 언로딩, 의존성 관리만 담당하는 메타 프레임워크다. 이 철학은 베이징대학과 DeepSeek가 공동 서명한 논문 "A Programming Paradigm for Spatiotemporal Composability"에서 비롯된다.

이 아키텍처는 각각 다른 기본 플러그인 세트를 로드하는 네 가지 에이전트 모드로 표현된다:

모드용도
표준(Standard)일상 에이전트 태스크를 위한 완전한 도구 조합
미니멀(Minimal)셸 + 파일 편집만 — 최소 환경 모델 벤치마킹용(V4 Flash 테스트에 사용된 모드)
크리에이티브(Creative)런타임 검사, 메모리에서 Cordis 플러그인 실험, 새 모드 구성
PTC(절차적 도구 호출)모델이 여러 도구 호출을 한 루프에서 연결하는 코드 생성

'모든 것이 플러그인' 철학은 DSH가 완성된 제품보다 조립 키트임을 의미한다 — 개발자가 어떤 형태로든 조립할 수 있는 에이전트용 레고 세트다. 100개 이상의 내장 플러그인과 성장하는 커뮤니티 기여 기반과 결합하여, 이 프레임워크는 도구가 아닌 플랫폼이 된다.

3. 트레이젝토리(Trajectory): 에이전트 관측성의 새 표준

DeepSeek Harness를 Codex급 제품과 가장 구별짓는 기능은 트레이젝토리(Trajectory)다 — 모델이 보는 모든 것을 기록하는 append-only 세션 로그: 시스템 프롬프트, 사고 연쇄, 도구 호출과 결과, 서브 에이전트 스케줄링, 모든 컨텍스트 주입.

트레이젝토리는 이벤트 수준에서 재생할 수 있어, 개발자는 모델이 어디서 오류를 냈는지, 각 단계가 몇 토큰을 소비했는지, 각 서브 에이전트가 무엇을 했는지 정확히 볼 수 있다. 세션은 동일한 이벤트 스트림에서 복원, 포크, 검색, 재생할 수 있다.

이는 에이전트 개발의 핵심 문제를 해결한다: 에이전트가 오래 실행되고 도구 체인이 복잡해질수록 전통적 채팅 요약은 블랙박스가 된다. 트레이젝토리는 에이전트에 모니터링·재생 창을 부여한다 — 모든 에이전트에 플라이트 레코더를 장착하는 것과 같다.

테크 미디어(지둥시)의 핸즈온 테스트에서, 프레임워크는 88페이지 PDF 논문을 22분 만에 번역했고(10개 서브 에이전트 파견), 미니멀 모드에서 스네이크 게임을 50초 만에 생성했으며, 1.4초 첫 토큰 레이턴시와 98% 캐시 히트율을 기록했다.

4. 오픈소스 에이전트 인프라가 브랜드와 개발자에게 의미하는 것

TMG의 오디언스 — 그리고 더 넓은 생태계 — 에게 DeepSeek Harness의 오픈소스 릴리스는 네 가지 함의를 갖는다:

함의 1: 에이전트 실행 레이어가 경쟁의 전장이 되었고, 그것은 오픈이다.

중국 AI 경쟁은 모델(파라미터 경쟁)에서 에이전트 실행 레이어로 이동했다. DeepSeek의 'Model + Harness = Agent' 공식은 수직 스택을 완성한다: 모델(V4 Flash/Pro) + 오픈 프레임워크(Harness) + 생태계(NPM 플러그인). 오픈소스 전략은 무료로 수정 가능한 대안을 제공함으로써 폐쇄형 에이전트 플랫폼(OpenAI Codex, Anthropic Claude Code)에 직접 도전한다.

함의 2: 에이전트 개발 비용이 빠르게 하락하고 있다.

오픈 플러그인 기반 프레임워크는 브랜드와 개발자가 플랫폼 락인 없이 맞춤형 에이전트를 구축할 수 있음을 의미한다. DeepSeek의 저가 모델(입력 100만 토큰당 1위안)과 '모든 것이 플러그인' 아키텍처를 결합하면, AI 에이전트 구축의 총비용이 크게 낮아졌다.

함의 3: 관측성이 브랜드급 요구사항이 된다.

트레이젝토리형 로깅 — append-only, 재생 가능, 포크 가능 — 은 에이전트 행동 투명성의 새 표준을 설정한다. 고객 대면 또는 운영 역할에 에이전트를 배포하는 브랜드에게 이 관측성은 AI 결정 감사, 장애 디버깅, 책임 있는 AI 사용 입증(9월 1일 AI 콘텐츠 라벨링 의무와 정렬)에 필수적이다.

함의 4: 8/17 인상이 무료 점심 시대의 종말을 알린다.

DeepSeek는 8월 17일 경 시행되는 대폭적인 API 가격 인상을 사전 예고했으며, 특히 캐시 비용이 대상이다. 같은 주의 'Harness + V4 Pro + 인상' 시퀀스는 DeepSeek가 생태계를 유료의 일관된 플랫폼으로 통합하고 있음을 보여준다 — DeepSeek 기반 에이전트를 채택하는 브랜드는 가격 전환을 예산화해야 한다.

  • 공식: "Model + Harness = Agent" — 하네스가 모델을 실제 환경의 에이전트로 변환
  • 아키텍처: '모든 것이 플러그인' — Cordis 플러그인 시스템, 4모드(표준/미니멀/크리에이티브/PTC), 100+ 플러그인
  • 트레이젝토리: append-only, 재생·포크 가능한 세션 로그 — 에이전트 관측성의 새 표준
